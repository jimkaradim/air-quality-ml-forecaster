# Before using this portfolio project for job applications

- [ ] Read and understand the code and feature engineering.
- [ ] Run `python scripts/download_data.py` with internet access.
- [ ] Run `python train.py` on the actual UCI dataset.
- [ ] Compare model and persistence baseline metrics in `artifacts/metrics.json`.
- [ ] If the model does not beat the baseline, describe the results accurately.
- [ ] Run `python -m pytest -q` and open `streamlit run app.py` locally.
- [ ] Add actual measured metrics/screenshots only after producing them yourself.
- [ ] Check dataset attribution and code license.
- [ ] Describe this as a newly built AI-assisted portfolio reconstruction, not your original lost university assignment.
- [ ] Never claim the model was deployed or used by real customers unless that happens.
