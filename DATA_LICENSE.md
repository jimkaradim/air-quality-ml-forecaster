# Dataset provenance and terms

Source: Song Chen, **Beijing PM2.5** (2015), UCI Machine Learning Repository, dataset ID 381.

- DOI: https://doi.org/10.24432/C5JS49
- Dataset page: https://archive.ics.uci.edu/dataset/381/beijing%2Bpm2%2B5%2Bdata
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- License link: https://creativecommons.org/licenses/by/4.0/

Hourly PM2.5 readings and meteorological measurements from Beijing, 2010–2014.
The source CSV is downloaded locally and **not committed** to this repository.
The project's MIT license applies to our source code, not the original dataset.

A public mirror is configured as a fallback in the downloader, but a dataset-schema
check rejects incompatible files rather than silently training on bad data.
